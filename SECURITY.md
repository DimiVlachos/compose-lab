# Security

compose-lab is a showcase rather than a shipped product, but if you find a security problem in it, for example in how the camera demo handles frames, please report it privately.

Use [GitHub's private vulnerability reporting](https://github.com/DimiVlachos/compose-lab/security/advisories/new) rather than a public issue. You'll get a reply within a week.

Only the latest commit on `main` is supported.
